# Catalog extensibility

This plan is closed as an implementation guide. Its scope was downstream
catalog composition, CLI identity, catalog provenance, and the single-tool
ownership guard. The original commit sequence is retained in Git history.

The [extensibility contract](../design/extensibility.md) describes the supported
public API and composition limits. [Update ownership](../design/updates.md)
defines switching tools and preserving repository edits.

Contributor instructions live in [AGENTS.md](../../AGENTS.md).
